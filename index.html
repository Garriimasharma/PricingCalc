What's included

Built for the plant floor, not the dashboard demo

Every Monitor+ machine gets the same core capability. What you configure below is how much data, how fast, and for how long.

Live data points
Track everything from temperature and vibration to cycle counts and pressure — up to 100+ signals per machine.
Configurable triggers
Set alert conditions on any signal. Get notified the moment a threshold is crossed, not after a shift ends.
Flexible sampling
Dial the read frequency from a slow, low-cost heartbeat to near real-time streaming, per machine.
Full history
Three months is included with every machine. Extend to a decade — or indefinitely — when you need the record.
ei3 Bridge
Optional secure remote connection into the machine for deeper diagnostics and support access.
Simple access
Anyone granted access sees the full configuration. No confusing permission tiers to manage.

Monitor+ is priced per machine, not by the byte. You choose how much you track, how often, and how long you keep it — everything else is included.
